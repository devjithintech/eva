The shift

Your team doesn't want another dashboard. They want a conversation.

Today, evaluating a candidate means hunting through tabs — returns here, risk flags there, peer correlations somewhere else — and stitching the picture together by hand. The tool makes you do the assembly.

We flip it. You ask out loud, the way you'd ask a colleague — and the interface builds the answer in front of you: the relevant chart, table, or scorecard, composed on demand and grounded in your own data.

The technology — and why it matters to you

Modern foundations, chosen for trust and longevity

Every piece earns its place against a question your committee would ask: can we trust it, will it last, and does it lock us in?

Generative UI · AG-UI protocol

An interface that composes itself

Built on AG-UI, the open standard for agent-to-application communication. The agent doesn't return text it hopes you'll read — it emits typed events that drive real, interactive components.

WhyDiligence in seconds, not tab-hunting — on an open standard with no proprietary dead end.
Model-agnostic core

Claude today, anything tomorrow

The AI provider sits behind a clean abstraction. Claude (Anthropic) is the default; Gemini and OpenAI are a one-line switch — selectable live, even mid-session.

WhyNo vendor lock-in. Best or cheapest model per task, and next year's models drop in without a rebuild.
Data integrity by design

The AI chooses the view, never the numbers

The model decides which view to render and for which funds. Every figure is sourced from your governed dataset on the server — the AI cannot invent a return or a Sharpe ratio.

WhyDefensible, audit-ready output — essential when a number drives an allocation.
Real-time streaming

Live answers, live collaboration

Server-Sent Events stream tokens and views the moment they're produced. Colleagues join the same session to evaluate a candidate together in real time.

WhyMatches how committees actually work — shared context, faster consensus.

Built for an allocator

Trust isn't a feature we added. It's the architecture.

  • Your keys never touch the browser.

    All AI credentials live server-side; the interface only ever talks to your own backend.

  • Numbers trace back to your source.

    Artifacts are populated from your data layer, not model memory — every figure on screen is one you can stand behind.

  • Runs today, with zero setup.

    The prototype runs end-to-end in a safe demo mode without any API key — so we can show it live, right now, and connect your models when you're ready.

  • Standards over silos.

    An open agent protocol and a typed, component-based frontend mean the system is inspectable, extensible, and yours to grow.
