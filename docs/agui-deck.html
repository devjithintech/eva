03what is AGUI

AI-powered UI that

Goal-driven, not click-driven. The interface is generated around what the user wants, and the agent executes the work.

the old loop

Define AGUI crisply: Agentic UI = an interface driven by user intent, where AI carries out the task and the UI is assembled to fit the moment. The one sentence to land: "Find → click → do" becomes "say → system does." Note the new loop literally has fewer steps — that compression is the value.

09risks & considerations

Power needs guardrails

the risk
  • Users don't trust the agent
  • The agent decides wrongly
  • No visibility into the "why"
the design answer
  • Explainability — show the reasoning
  • Controls — pause, edit, override, undo
  • Guardrails — block unsafe actions
Showing the risks makes you more credible, not less — it signals you've thought past the demo. The honest danger to name out loud is overtrust: a confident, fluent agent that's quietly wrong, with the user not checking. Every risk on the left has a design answer on the right — that mapping is the designer's job, and it's why this needs us.

03why streaming wins

The felt-experience argument. A traditional dashboard computes then paints once at ~3s; we stream, so first words land at ~0.4s and the view fills in by ~2.5s. Perceived latency, not total compute, is what users judge — this is the chart that wins that argument.
